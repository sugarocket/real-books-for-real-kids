## ✨ Project Objective

**Real Books for Real Kids** empowers parents, teachers, caregivers, and educators to create personalized, high-quality illustrated picture books instantly — powered by Grok AI.

| What | How |
|------|-----|
| 📖 Browse | Pre-generated showcase books ready to read |
| ✍️ Create | Personalized books from simple prompts |
| 🔄 Regenerate | Try again if not satisfied — same inputs, fresh story & illustrations |
| 🎨 Illustrate | Grok-generated cartoon illustrations per page |
| 🔊 Listen | Grok Voice narration (TTS) with natural speech |
| 💾 Keep | Save & download your creations (PDF export) |

---

## 🤖 AI Generation Guidelines

Grok AI follows strict guidelines for safe, high-quality content:

- ✅ Transform minimal input → rich, educational, age-appropriate stories
- ✅ Cultural sensitivity, positive representation, strict safety
- ✅ Seamless text + illustration integration per page
- ✅ Flexible page text: image-only, single word, punctuation, or sentences — AI adapts
- ✅ Prompt expansion: topic + age + keywords → creative, coherent narrative
- 🚫 No hate, NSFW, violence, or unsafe content

## 🧩 User Inputs (Book Creation)

| Input | Type | Required |
|-------|------|----------|
| **Keywords / Ideas** | Text (≥3 words) | ✅ Mandatory |
| **Topic / Story Idea** | Dropdown | ✅ Mandatory |
| **Age Group** | Dropdown (0–2 / 3–4 / 5–6) | ✅ Mandatory |
| **Page Count** | Dropdown (3–8 pages) | ✅ Mandatory |
| **Illustration Style** | Dropdown + "Random ✨" | ✅ Mandatory |
| **Diversity & Inclusion** | Dropdown | Optional |
